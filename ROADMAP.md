# Roadmap

What could come next. None of it is promised; all of it is open to contributors. Comment on an issue or start a [discussion](https://github.com/nrzz/claude-code-starter-kits/discussions) before a large change.

- Kits for Rust (cargo), PHP (Laravel, Composer), Ruby (Rails, Bundler) and Swift.
- Monorepos: one CLAUDE.md per package when stacks live in subfolders.
- Detecting test frameworks in more detail (Jest vs Vitest vs node:test).
